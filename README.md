# Гитарные тренажёры

**Тренажёр боя** (`index.html`) — конструктор гитарного боя: собираешь партию из тактов (бой + аккорд + число повторов),
жмёшь «Старт» и играешь под синтезированную гитару с метрономом и отсчётом.

**Открыть:** https://vzeberg.github.io/guitar-trainers/

## Что умеет

- **Партия** — последовательность тактов, каждый со своим боем, аккордом и числом повторов; такты перетаскиваются.
- **Бои** — редактор рисунка тапом по кружку (вниз › вверх › не бьётся), длина 8 или 16 ходов, свои названия, прослушивание по одному.
- **Аккорды** — палитра со схемами аппликатур; во время игры видно предыдущий, текущий и следующий аккорд.
- **Звук** — щипок струны по Карплюсу-Стронгу, бренчание сверху вниз и снизу вверх, метроном, отсчёт на такт.
- **Шпаргалка** — структура песни; показывается, только если для текущего названия есть запись в `CHEATS`.
- **Оффлайн** — ставится на домашний экран, работает без сети (service worker).

## Устройство

Одна страница без сборки — открывается двойным кликом по файлу.

| Файл | Что это |
| --- | --- |
| `index.html` | всё приложение: разметка, стили, логика |
| `sw.js` | service worker, оффлайн-кэш |
| `manifest.webmanifest`, `icon*.png`, `icon.svg`, `apple-touch-icon.png` | PWA-обвязка |
| `perebor.html` | второй тренажёр — перебор, отдельная страница и своё хранилище |
| `dvurechie-trainer.html` | редирект со старого адреса на `./` |

Внутри `index.html` логика идёт сверху вниз: модель и аппликатуры → состояние и его
валидация → редакторы → аудио → планировщик → экран игры.

### Данные

Состояние лежит в `localStorage` под ключом `guitar-trainer:state:v1` и при загрузке
прогоняется через `sanitize()` — каждое поле проверяется отдельно, поэтому одно битое
значение не обнуляет партию. Ключи прошлой версии (`dvurechye-trainer-v4`,
`trainer-song-name`, `trainer-show-diagrams`) переносятся автоматически один раз.

iOS стирает `localStorage` сайтов, куда не заходили неделю, поэтому в разделе
«Сохранение» есть выгрузка и загрузка настроек файлом.

### Добавить шпаргалку для своей песни

Дописать запись в `CHEATS` — ключ равен названию песни в нижнем регистре; кнопка
«Шпаргалка» появится, как только название в шапке совпадёт с ключом.

### Иконки

PNG собраны из `icon.svg` headless-хромом:

```sh
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --hide-scrollbars --force-device-scale-factor=1 \
  --window-size=512,512 --screenshot=icon-512.png file://$PWD/wrap.html
```

где `wrap.html` — страница с `<img src="icon.svg">` нужного размера.

## Тренажёр перебора

`perebor.html` — вторая, самостоятельная страница: та же вёрстка и тот же синтез, но
партия играется щипком, а не боем. Открывается по прямому адресу
(`…/guitar-trainers/perebor.html`); из Safari её можно добавить на домашний экран —
`apple-mobile-web-app-*` в шапке есть, иконка общая с тренажёром боя.

- **Такт — всегда 4/4**, а дробление задаётся на каждый перебор: четыре щипка
  четвертями или восемь восьмыми. Такт при этом длится одинаково, меняется только шаг.
  Восьмые нужны для фигур, которые в четыре слота не лезут, — например припевной
  `Б-3-(21)-(21)-3` в пять щипков, где вторая `(21)` стоит на восьмой между 3-й и 4-й долей.
- **Перебор** рисуется сеткой табулатуры на своём экране («Настроить переборы» в разделе
  02 — сетки занимали пол-конструктора): строки — струны (сверху 6-я толстая), столбцы —
  щипки, над долями стоят цифры, между ними «и». Имя не хранится, а собирается из рисунка:
  `5-3-(21)-3`. Верхняя строка «Б» — бас текущего аккорда, он берётся из аппликатуры
  (самая толстая незаглушённая струна), поэтому один перебор `Б-3-(21)-3` правильно звучит
  и на Am (5), и на Dm (4), и на E (6). Последний щипок погасить нельзя: перебор без
  щипков всё равно был бы выброшен при загрузке.
- **Песня** — разделы (Вступление, Куплет, Припев) с повтором у каждого; перебор
  выбирается на раздел, а в такте переопределяется только там, где нужен переход.
  У каждого раздела своя кнопка «Тренировать раздел» — играется он один, по кругу,
  и кнопка «⧉» — копия раздела целиком: припевы по ходу песни отличаются парой аккордов,
  собирать их заново смысла нет.
- **Раздел-рифф** — второй тип раздела: вместо «аккорд + перебор» в каждом щипке стоит
  одна нота, заданная струной и ладом. Это для мест, где играется не аккомпанемент, а
  мелодическая линия: ноты выше аппликатуры перебором невыразимы в принципе. Тап по щипку
  открывает выбор струны и лада, нота сразу звучит — рифф можно снимать на слух.
- **Пауза на смену аккорда** — 0–8 долей тишины перед тактом, но только если аккорд
  действительно меняется; одинаковые подряд играются встык. Метроном на паузе не
  замолкает, а на экране заранее показывается схема того аккорда, куда переставлять
  пальцы, и обратный счёт. Задаётся в долях, поэтому с «Разгоном» пауза сжимается
  вместе с темпом.
- **Разгон** — темп сам растёт на N BPM каждые M кругов, пока не упрётся в 300. «Стоп»
  возвращает темп к тому, с которого начинали: разогнанное значение в хранилище не остаётся.
- **Метроном отбивает доли, а не щипки** — при восьмых клик приходится только на доли.
- `×` в аппликатуре значит «не задевать при бое», а не «струну нельзя щипнуть»: пальцы
  её не прижимают, значит она открытая. Поэтому `5-3-(21)-6` на Am берёт с шестой
  низкое Ми — ту самую басовую связку, ради которой такой перебор и нужен. Подставляется
  только шаг «Б».

### Пресет «Серебро»

Стартовое состояние — разбор «Серебра» Би-2 по видеоуроку Гитарист ТВ (акустическая
версия): четыре аккорда, шесть переборов, вступление, куплет и два припева, темп 86.
Собирается функцией `presetSerebro()`. Кнопка «Загрузить «Серебро» целиком» стоит прямо
в разделе 01, над списком разделов: она возвращает песню поверх чего угодно собранного,
в каком бы виде конструктор ни был. Без неё до пресета не добраться — `localStorage`
перебивает дефолт.

В уроке рисунок расписан по аккордам (`5-3-(21)-3` на Am, `6-3-(21)-3` на F,
`4-3-(21)-3` на Dm), но первый щипок везде — бас аккорда, поэтому через «Б»
одиннадцать строк урока сводятся к четырём фигурам.

Чего в пресете нет и почему: вступление, оба проигрыша и концовка на записи — не
аккомпанемент, а одноголосная линия на 1–3 струнах в районе V–XIII ладов с hammer-on
и флажолетом. Урок заменяет её арпеджио на Am, пресет следует уроку. Для настоящей
линии есть раздел-рифф, но ноты туда не вписаны: по текстовым источникам они
восстанавливаются приблизительно, а выдавать догадку за разбор хуже, чем оставить пусто.

Состояние лежит отдельно от боя, под ключом `guitar-trainer:perebor:v1`, и так же
прогоняется через свой `sanitize()`. Выброшенный пустой перебор не сдвигает чужие
ссылки: индексы переезжают по карте, иначе раздел молча начинал бы играть соседний
рисунок.

## Деплой

GitHub Pages из корня ветки `main` — пуш в `main` и есть деплой. После выката
service worker обновляется сам: HTML берётся из сети, старые кэши чистятся при активации.
Если менялся список `SHELL_FILES`, поднять `VERSION` в `sw.js`.
