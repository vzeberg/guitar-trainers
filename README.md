# Тренажёр боя

Конструктор гитарного боя: собираешь партию из тактов (бой + аккорд + число повторов),
жмёшь «Старт» и играешь под синтезированную гитару с метрономом и отсчётом.

**Открыть:** https://vzeberg.github.io/guitar-trainers/

## Что умеет

- **Партия** — последовательность тактов, каждый со своим боем, аккордом и числом повторов; такты перетаскиваются.
- **Бои** — редактор рисунка тапом по кружку (вниз › вверх › не бьётся), длина 8 или 16 ходов, свои названия, прослушивание по одному.
- **Аккорды** — палитра со схемами аппликатур; во время игры видно предыдущий, текущий и следующий аккорд.
- **Звук** — щипок струны по Карплюсу-Стронгу, бренчание сверху вниз и снизу вверх, метроном, отсчёт на такт.
- **Шпаргалка** — структура песни; показывается, только если для текущего названия есть запись в `CHEATS`.
- **Оффлайн** — ставится на домашний экран, работает без сети (service worker).

## Устройство

Одна страница без сборки — открывается двойным кликом по файлу.

| Файл | Что это |
| --- | --- |
| `index.html` | всё приложение: разметка, стили, логика |
| `sw.js` | service worker, оффлайн-кэш |
| `manifest.webmanifest`, `icon*.png`, `icon.svg`, `apple-touch-icon.png` | PWA-обвязка |
| `dvurechie-trainer.html` | редирект со старого адреса на `./` |

Внутри `index.html` логика идёт сверху вниз: модель и аппликатуры → состояние и его
валидация → редакторы → аудио → планировщик → экран игры.

### Данные

Состояние лежит в `localStorage` под ключом `guitar-trainer:state:v1` и при загрузке
прогоняется через `sanitize()` — каждое поле проверяется отдельно, поэтому одно битое
значение не обнуляет партию. Ключи прошлой версии (`dvurechye-trainer-v4`,
`trainer-song-name`, `trainer-show-diagrams`) переносятся автоматически один раз.

iOS стирает `localStorage` сайтов, куда не заходили неделю, поэтому в разделе
«Сохранение» есть выгрузка и загрузка настроек файлом.

### Добавить шпаргалку для своей песни

Дописать запись в `CHEATS` — ключ равен названию песни в нижнем регистре; кнопка
«Шпаргалка» появится, как только название в шапке совпадёт с ключом.

### Иконки

PNG собраны из `icon.svg` headless-хромом:

```sh
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --hide-scrollbars --force-device-scale-factor=1 \
  --window-size=512,512 --screenshot=icon-512.png file://$PWD/wrap.html
```

где `wrap.html` — страница с `<img src="icon.svg">` нужного размера.

## Деплой

GitHub Pages из корня ветки `main` — пуш в `main` и есть деплой. После выката
service worker обновляется сам: HTML берётся из сети, старые кэши чистятся при активации.
Если менялся список `SHELL_FILES`, поднять `VERSION` в `sw.js`.
